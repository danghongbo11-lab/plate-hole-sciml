# Dataset

The operator-learning dataset contains 51 parameterized Python FEM cases.

- Hole radius: `R in [0.20, 0.35]`
- Output grid: `32 x 64`
- Stored fields: `R`, `X`, `Y`, `mask`, `U1`, `U2`
- Geometry: a finite `4 x 2` plate with a circular hole centered at `(2, 1)`

`fno_dataset.npz` is generated by:

```bash
python fem/generate_fno_dataset.py
```

The Python FEM pipeline is used to generate the parameterized training data. Abaqus is used only as an independent validation reference for the `R = 0.25` case.
